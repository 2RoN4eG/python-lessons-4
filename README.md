## Задача 1  
Дан список чисел. Поменять местами первый и последний четные элементы.

**Примеры**
- Дано: `[5, **8**, 7, 3, 10, 11, **4**, 9]`
  Результат: `[5, 4, 7, 3, 10, 11, 8, 9]`

- Дано: `[**12**, 5, 7, **6**, 9]`
  Результат: `[6, 5, 7, 12, 9]`

---

## Задача 2  
Дан список чисел. Найти сумму чисел между максимальным и минимальным числом в списке. Если максимальных/минимальных значений несколько - учитывать первое вхождение как старт и последнее как стоп.

**Примеры**
- Дано: `[4, **1**, 7, 9, 12, 5, 3, 6, **12**]`
  Результат: `42`

- Дано: `[9, **15**, 7, 9, 3, 8, 3, 10, **3**]`
  Результат: `40`

---

## Задача 3  
Даны два списка чисел. Нужно создать третий список, содержащий:

- элементы первого списка, которых **нет** во втором;
- элементы второго списка, которых **нет** в первом.

То есть требуется получить элементы, **уникальные для каждого списка**.

**Примеры:**  
- Дано: `A = [1, 2, 3, 4]`, `B = [3, 4, 5, 6]`  
  Результат: `[1, 2, 5, 6]`

- Дано: `A = [10, 20, 30]`, `B = [20, 40]`  
  Результат: `[10, 30, 40]`

---

## Задача 4*  
Дан список температур по дням.  
Нужно определить **количество изменений направления**:

- рост → падение — одно изменение;  
- падение → рост — одно изменение.

Подряд идущие дни с одинаковым направлением считаются одним участком.

**Пример:**  
`[10, 12, 14, 15, 9, 5, 3, 8, 9, 10, 9]` → `3`  
(рост → падение → рост → падение)

---

## Задача 5*
Проверить **симметрична** ли квадратная матрица относительно **побочной диагонали**.
Дан список списков размера N × N. 

Побочная диагональ — это диагональ, проходящая от **верхнего правого угла к нижнему левому**.

Вывести YES, если симметрична, иначе NO.

**Пример**
- Дано
`[
    [1, 2, 3],
    [4, 5, 2],
    [3, 4, 1]
]`
Результат: YES

- Дано:
`[
    [7, 8, 9],
    [1, 5, 3],
    [9, 2, 7]
]`
Результат: NO
